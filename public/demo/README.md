- Embedded VRM metadata permits use by everyone, corporate commercial use, modification, and redistribution. Credit is unnecessary. We still identify VRoid Project in the product UI and repository notices.
- Modification: embedded textures larger than 512 pixels are downscaled for a faster, lower-memory web preview. Geometry, humanoid mapping, expressions, license metadata, and spring-bone definitions are retained.
